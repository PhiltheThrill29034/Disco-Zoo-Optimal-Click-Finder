## Minimum Set Cover Algorithm

I was inspired to solve this problem by the game Disco Zoo. 

In the game, each animal has a specific pattern, a set of points in a 5x5 grid. Your job is to figure out those patterns, click all the points that make up the animal's pattern and rescue it.

The question this aroused in me was this: given a pattern, what is the minimum number of points I have to click to eliminate all possible repositions?

I decided to build this so I can figure out, for any pattern, how to make the least amount of attempts to find the animal
